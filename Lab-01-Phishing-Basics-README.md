## 🔬 Practical Work

I completed a controlled phishing simulation in TryHackMe.

The exercise involved:

1. Setting up the simulated phishing environment.
2. Creating a simulated credential-harvesting page.
3. Using the provided simulated webmail environment.
4. Sending a simulated phishing email.
5. Observing the simulated credential capture.
6. Understanding how the phishing attack worked.

> **Note:** All activities were performed only inside the authorized TryHackMe training environment.

## 💡 Key Takeaways

- Phishing attacks can abuse human trust to obtain sensitive information.
- Fake login pages can be used to collect credentials.
- Look-alike domains can make phishing websites appear legitimate.
- Urgency can pressure users into making mistakes.
- Understanding the attack process helps defenders build better detection and awareness systems.
